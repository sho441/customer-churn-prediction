# customer-churn-prediction
Kaggle Playground (Customer Churn Prediction) を用いた顧客離脱予測モデルの構築・機械学習ポートフォリオ

## 1.プロジェクトの概要
架空の通信会社の契約データをもとに、顧客の解約（離脱）を高精度に予測するモデルを構築。
予測手法として10種の学習モデルの比較・検証を行い、最終的にCatBoostほか4種を組み合わせたアンサンブルモデルを採用。
予測精度の向上だけでなく、どのような特徴量が解約に強く影響しているかを分析し、ビジネス上のインサイトを導出しました。

## 2.ビジネス・研究的な背景
サブスクリプション型のビジネスや通信事業において、既存顧客の離脱（解約）防止は収益を守る上で極めて重要です。
新規顧客の獲得コストに比べ、既存顧客の維持コストは低い傾向があるため、あらかじめ「解約しそうな顧客」を高い精度で特定し、
事前にアプローチ（キャンペーンの案内やプランの見直しなど）を行うための早期検知モデルの構築が求められます。
本プロジェクトでは、実務を想定した厳格な検証環境下で高精度な離脱予測モデルの検証を行いました。

## 3.使用した技術・ライブラリ
・言語: Python (3.0)
・データ処理・分析: Pandas, NumPy, Scikit-learn
・機械学習モデル: LightGBM, XGBoost, CatBoost, RandomForest, Logistic Regression, LinearSVC 他
・ハイパーパラメータ最適化: Optuna
・検証手法: ネステッド交差検証 (Nested Cross-Validation, 5-Fold), ターゲットエンコーディング

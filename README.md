# customer-churn-prediction
Kaggle Playground (Customer Churn Prediction) を用いた顧客離脱予測モデルの構築・機械学習ポートフォリオ

## 1.プロジェクトの概要
架空の通信会社の契約データをもとに、顧客の解約（離脱）を高精度に予測するモデルを構築。
予測手法として10種の学習モデルの比較・検証を行い、最終的にCatBoostほか4種を組み合わせたアンサンブルモデルを採用。
予測精度の向上だけでなく、どのような特徴量が解約に強く影響しているかを分析し、ビジネス上のインサイトを導出しました。

## 2.ビジネス・研究的な背景
サブスクリプション型のビジネスや通信事業において、既存顧客の離脱（解約）防止は収益を守る上で極めて重要です。
新規顧客の獲得コストに比べ、既存顧客の維持コストは低い傾向があるため、あらかじめ「解約しそうな顧客」を高い精度で特定し、
事前にアプローチ（キャンペーンの案内やプランの見直しなど）を行うための早期検知モデルの構築が求められます。
本プロジェクトでは、実務を想定した厳格な検証環境下で高精度な離脱予測モデルの検証を行いました。

## 3.使用した技術・ライブラリ
* **言語**: Python (3.0)

* **データ処理・分析**: Pandas, NumPy, Scikit-learn

* **機械学習モデル**: LightGBM, XGBoost, CatBoost, RandomForest, Logistic Regression, LinearSVC 他

* **ハイパーパラメータ最適化**: Optuna

* **検証手法**: ネステッド交差検証 (Nested Cross-Validation, 5-Fold), ターゲットエンコーディング

## 6.アプローチと工夫点
### ① 厳格な検証設計

&emsp; ・データリークを防ぎ、未知のデータに対する真の汎用性能を正しく評価するため、ネステッド交差検証を採用。

### ② ドメイン知識に基づく高度な特徴量エンジニアリング

・実データ特有の法則性（tenure * MonthlyCharges ≈ TotalCharges）に着目し、理論値との乖離率や欠損値の論理的補完を実施。

・カテゴリカル変数に対するターゲットエンコーディング（TE）や、N-gram（Bi-gram/Tri-gram）による組み合わせ特徴量の生成。

・離脱者・継続者の分布に基づいた条件付きパーセンタイルランクや四分位数からの距離差分特徴量の作成。

### ③ 複数モデルの比較と重み付きアンサンブル

・10種類のアルゴリズム（勾配ブースティング系、線形モデル等）を比較・検証。

・OptunaによるLightGBMのハイパーパラメータチューニングを実施後、各モデルのOut-of-Fold (OOF) 予測に対して scipy.optimize（SLSQP）を用いて最適な重みを算出し、精度を最大化。

## 7.結果と考察
### ・予測精度

・単体モデルおよび最適化された重み付きアンサンブルにより、安定した高い ROC-AUCスコア (5-Fold CV OOF ROC-AUC: 0.91667) を達成。過学習を抑えつつ、実務に耐えうる汎用性を確認。

### ・特徴量重要度（解約要因のインサイト）の分析

・特徴量重要度や係数の分析から、契約期間（tenure）や契約プラン（Contract）、特定のネット接続サービス（InternetService）の利用状況が顧客の離脱に大きな影響を与えていることを特定。

・どのような顧客セグメントで離脱リスクが高まるかの傾向を可視化し、具体的なリテンション施策（解約防止キャンペーンのターゲティングなど）への応用可能性を確認。

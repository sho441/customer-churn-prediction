# customer-churn-prediction
Kaggle Playground (Customer Churn Prediction) を用いた顧客離脱予測モデルの構築・機械学習ポートフォリオ

## 1.プロジェクトの概要
架空の通信会社の契約データをもとに顧客離脱を予測。
予測手法として10種の学習モデル検討を実施し、最終的にCatBoostほか4種を組み合わせたアンサンブルモデルを採用し、
予測精度の算出とどのような特徴量が強く影響しているかを分析した。

## 2.ビジネス・研究的な背景
顧客離脱を防ぐための早期検知モデルの構築

## 3.使用した技術・ライブラリ
Python, Pandas, Scikit-learn, LightGBM, Matplotlib
